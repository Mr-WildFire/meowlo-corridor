## 6. 技术规格

- 设计基准：**1920×1080**
- 源图建议 2×（3840×2160），再导出 1920
- PNG-24/32，sRGB，透明
- UI 图集 2048×2048
- 9-slice 必须标 border（上/下/左/右）
- 按钮至少 4 态：normal / pressed / disabled / highlight
- 难度卡 3 态：normal / pressed / selected
- 不把中文/英文文字烘进图片
- 图标统一线宽和圆角
- 英文文案按中文长度的 1.3–1.5 倍留空间
