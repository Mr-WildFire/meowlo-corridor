# 《喵音回廊》资源需求清单

> 版本：v1.0　|　日期：2026-10-18  
> 说明：当前 `assets/resources/art/` 下的图是程序生成的**占位资源**，不是正式 UI；不满意是正常的。本文只梳理正式资源需求，不再继续加占位图。

## 0. 先明确一件事

当前 UI 不是“图片 UI”，大部分是运行时 `Graphics + Label` 画的：

- HUD 文本、Toast、教学卡、结算 Overlay
- 难度菜单卡片、设置页面板、按钮、滑条
- 方向键、暂停/静音/设置按钮

所以正式 UI 资源不是“丢几张图进去”就会自动生效，需要同时替换 `MenuView / HudView / SettingsView` 里的 Graphics 绘制逻辑。

建议正式资源按“**UI 图集 + 9-slice + 图标 + 字体**”交付，代码侧增加一个统一的 `UiSkin` 加载/换肤层。

## 1. 视觉方向建议

推荐方向：**温暖手绘绘本风 + 深色回廊 + 青蓝音波光**。

- 猫：琥珀橘、奶油白、苔绿眼睛，边缘略手绘
- 回廊：深紫黑、木地板、旧墙、暖色壁灯
- 音乐元素：青蓝音符、声波环、CD 虹彩
- UI：奶油色纸张/半透明深色玻璃，边角圆润，不要纯黑直角
- 避免：扁平矢量占位感、纯黑背景、系统默认按钮、文字直接压在复杂纹理上

建议色板：

## 5. 音频资源

### 5.1 音乐

| 资源 | 规格 | 说明 |
|---|---|---|
| 6 层分轨 | OGG，48kHz，48 秒循环 | 80 BPM，D 小调；同长度、同起点 |
| 高潮 | OGG，4–6 秒 | 与分轨同 BPM/调性 |
| 菜单环境 | OGG，30–60 秒循环 | 可选 |
| 层命名 | ambient/bass/rhythm/melody/harmony/counter | 与现路径一致 |

要求：

- 6 层必须能**逐层叠加不打架**
- 1 秒静音后高潮要明显更响但不削波
- 建议整体 -18 LUFS，高潮 -11 LUFS，True Peak ≤ -1 dB
- 提供 loop 起点/终点标记

### 5.2 音效

| 音效 | 时长 | 用途 |
|---|---:|---|
| 点击 | 60–100ms | 菜单 |
| 拾取碎片 | 250–400ms | 拾取 |
| 通关 | 1.5–2s | 结算 |
| 超时 | 1–1.5s | 主人抱走 |
| 脚步 | 60–100ms | 移动，轻 |
| 撞墙 | 100ms | 可选 |
| 60s/30s 提示 | 300ms | 时间警告 |
| 开门/光柱 | 1s | 出口出现 |

## 6. 字体与本地化

- 中文 + English 都必须覆盖
- 中文不能是“缺字回退系统字体”的效果
- 标题 1 套、正文 1–2 套即可
- 需要提供：
  - `.ttf`/`.otf`
  - 授权说明（商用/比赛展示）
  - 字重（Regular/Bold）
  - 字符集范围（至少常用 3500 汉字 + 英文/标点）
- 英文文案比中文长 30–50%，UI 要留余量，不能把文字烘进图片

## 7. 动画/VFX 规格

- 猫：4 方向，行走 8–12 fps，待机 4–6 fps
- 蝴蝶/萤火虫：8–12 fps 循环
- 碎片：旋转/浮动/闪光；可用 Shader 或 4 帧
- 出口：光柱 + 门；光柱可用 Shader，不必须贴图
- CD 拼合：当前是代码动画，正式可用“碎片→CD”序列帧/粒子替换
- UI：按钮按下缩放 0.95、面板淡入 0.15s；不要过度弹跳

## 8. 路径与命名

现有路径不要随意改，否则要改代码：

```text
assets/resources/art/
├─ cat/cat_{down,up,left,right}_{0..3}.png
├─ board/floor.png
├─ board/wall.png
├─ props/fragment.png
├─ props/{butterfly,firefly,wine,cat_strip,sewer,fish,yarn,feather}.png
├─ props/exit.png
├─ props/cd.png
├─ props/owner.png

```

建议新增：

```text
assets/resources/art/ui/
├─ panels/panel_9slice.png
├─ buttons/button_9slice.png
├─ icons/*.png
├─ slider/track.png
├─ slider/fill.png
├─ slider/knob.png
└─ logo_zh.png / logo_en.png

assets/resources/audio/
├─ music/music_*.ogg
├─ sfx/sfx_*.ogg
└─ menu/menu_ambient.ogg

assets/resources/fonts/
├─ title.ttf
└─ body.ttf
```

命名规则：

- 全小写、下划线
- 不用“最终版/新版/改改改”
- 状态后缀：`_normal/_pressed/_disabled`
- 9-slice 用 `_9slice`
- 不要用中文文件名（跨平台/命令行构建容易出编码问题）

## 9. 技术规格

### 图片

- PNG-24/32，透明背景
- 不把文字烘进图片（除 Logo）
- UI 图集建议 2048×2048，单图留 4px padding
- 9-slice 必须标清 border（上/下/左/右）
- 设计基准 1080×1920；安全区上下各留 80–120px
- 颜色空间 sRGB；不要用 CMYK
- 单张 UI 图不超过 2MB，整包 UI 图集控制在 8–12MB

### 音频

- OGG Vorbis，48kHz
- 音乐循环点准确，层间 sample 对齐
- SFX 单声道，峰值 -3dB 左右
- 总音频建议 < 15MB

### 字体

- TTF/OTF，避免只给图片字
- 字体文件命名英文
- 确认 Cocos Label 支持该字体（Cocos 3.8 对 TTF 支持正常）

## 12. 验收标准

- 1080×1920 下 UI 不重叠、不超出安全区
- 中文/English 切换后不溢出
- 9-slice 拉伸不变形
- 按钮 4 态清晰
- 图标在深色背景上可辨认
- 猫行走无跳帧/滑步
- 地板平铺无缝
- 6 层音乐循环无爆音、层同步
- 1 秒静音后高潮明显
- 所有资源按上述路径替换后，**不需要改游戏逻辑**
