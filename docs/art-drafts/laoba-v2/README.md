# 老八 v2 角色图评估

这三张已从 Downloads 复制到项目内，原文件不再改动。

## 文件

| 文件 | 尺寸 | 评价 |
|---|---:|---|
| `laoba_side.png` | 2048×1152 | 最好的一张，3/4 侧视，体型自然，适合做风格锚点 |
| `laoba_front.png` | 2048×1152 | 可爱，但偏 Q 版、身体短、像坐姿，和侧视不是同一体型 |
| `laoba_back.png` | 1024×576 | 背面偏小、腿短、尾巴位置和侧视不一致 |

## 共同优点

- 海豹双色布偶猫方向正确
- 深色面罩/耳朵/尾巴、蓝眼睛、白胸白爪
- 暗红项圈 + 小黑胶吊牌
- 卡通线条、平涂风格统一
- 侧面那张的剪影和表情最好

## 主要问题

1. **三张不是同一体型**
   - 侧视自然、身体长
   - 正面/背面明显 Q 版、头大身短
2. **正面不是标准站姿**
   - 身体低、前腿伸，像坐着
3. **背面尺寸和比例不对**
   - 1024×576，腿短，尾巴方向与侧视不一致
4. **没有纯左侧/右侧**
   - 侧视是 3/4，不是正交侧视图
5. **背景 alpha 不干净**
   - 有半透明白边/彩色边缘，不能直接进 Cocos
6. **不能直接做 4 方向动画**

## 建议

- **保留 `laoba_side.png` 作为风格锚点**，可用于菜单/标题插画参考
- 不要直接把三张切成 sprite
- 如果确定 Q 版：重做侧视，让侧视也 Q
- 如果确定自然比例：重做正面/背面，把头缩小、身体拉长、腿加长
- 统一后再做：正面 / 左侧 / 背面 / 右侧 / 行走 6–8 帧

## 下一步

1. 先定体型：轻 Q 版还是自然比例
2. 以 `laoba_side.png` 为参考，生成同体型的正面/背面
3. 去背景、去半透明边缘、裁切到透明 PNG
4. 统一 512×512 或 256×256
5. 再进 `assets/resources/art/cat/`

当前只是**项目内评估稿**，没有接入游戏资源路径。
