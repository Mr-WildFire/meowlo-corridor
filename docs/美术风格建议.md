# 《喵音回廊》美术风格建议

> 版本：v1.0　|　日期：2026-10-18  
> 目标：让比赛 Demo 从“占位扁平风”变成有辨识度的完整作品，同时控制小团队制作成本。

## 1. 一句话方向

> **一座被猫重新点亮的旧唱片回廊：深紫纸雕空间，琥珀色猫是唯一暖源，青蓝音符是唯一冷光，UI 像旧唱片封套和票根。**

推荐关键词：

```text
纸雕绘本 / 旧唱片 / 微光
```

不是纯黑极简，也不是霓虹赛博，更不是写实恐怖。  
核心是“**暗房间里的一盏暖灯**”：回廊越暗，猫和音乐的光越珍贵。

## 2. 为什么推荐这个方向

### 和玩法匹配

- 2 格视野本来就是“黑暗里靠近光”，纸雕层叠和暗部很适合遮罩
- 猫是唯一暖色，玩家视线自然跟着猫走
- 碎片/音符/出口用青蓝冷光，和暖色猫形成强对比
- CD、唱片、票根天然适合音乐主题的 UI

### 和成本匹配

- 纸雕/分层平涂比厚涂水彩便宜
- 靠形状、纸张纹理、投影和光色出效果，不靠高细节
- 小团队可以逐张替换，不需要一次性重做全部
- 1080×1920 手机屏幕上，中等细节就足够

### 和比赛展示匹配

- 比“纯黑 + 系统字”有记忆点
- 比像素风更适合音乐、雾气、光晕
- 比写实风更不容易翻车
- 答辩时一句话能讲清楚：“纸雕绘本里的唱片回廊”

## 3. 色彩规则

```text
#0B0713  深回廊底
#1C1426  面板/暗部
#3A2A2A  旧木地板
#F3E7D3  奶油纸/文字
#F2B35C  琥珀：猫、灯、重要按钮
#8FD3D6  青蓝：音符、碎片、出口
#C96A7A  玫瑰：危险/反向/超时
#9FE0C0  薄荷：恢复/成功
```

使用比例：

```text
70% 深色空间
20% 琥珀暖光
10% 青蓝冷光
```

不要：

- 大面积纯黑 `#000000`
- 高饱和霓虹紫/蓝
- 每个道具都用不同高饱和色
- UI 和场景抢同一个视觉焦点

## 4. UI 风格：旧唱片封套 + 票根

### 菜单

- 背景：回廊深处 + 悬挂的旧唱片/声波
- 难度卡：像三张**唱片封套**或**演出票根**
- 选中态：封套微微抽出，露出一圈黑胶边缘
- 标题：手写感/旧印刷体，奶油色，少量琥珀描边
- 按钮：纸张/黄铜，不要玻璃拟态

### HUD

- 顶部信息条像一张**曲目单/磁带标签**
- 音轨进度用“黑胶纹路 + 音符”
- 倒计时像旧式**磁带计数器**
- 碎片用“黑胶碎片”，不要通用水晶
- Toast 像一张**小票/便签**
- 教学卡像**唱片内页**

### 设置页

- 像调音台/唱机控制面板
- 音量滑条 = 推子
- 静音 = 唱针抬起
- 语言切换 = 印章/标签
- 震动开关 = 机械拨杆

### 结算

- 通关：完整 CD 从碎片中拼合，放在封套上
- 超时：主人剪影 + 暖色门光，不要恐怖化
- 星级：像唱片评级印章，不是通用五角星

## 5. 角色：老八

- 琥珀橘虎斑，奶油白口鼻，苔绿眼睛，暗红项圈 + 琥珀吊牌
- 比例：大头、短腿、圆身体，尾巴表情丰富
- 轮廓：略手绘、不完全对称；不要纯几何圆
- 行走：4 方向 × 8 帧，脚步有轻微压缩/回弹
- 待机：呼吸、眨眼、尾巴慢摆
- 拾取：耳朵前倾、尾巴竖起
- 被抱起：身体拉长、爪子蜷起
- 表情：好奇 > 可爱 > 惊恐；不要过度卖萌

## 6. 场景：旧唱片回廊

- 地板：深色木地板/旧地毯，512 可平铺，木纹低对比
- 墙：旧墙纸/木墙 + 少量唱片/海报残片，但不能每格都花
- 灯光：猫附近一圈暖光；出口/碎片青蓝冷光
- 装饰：每隔几格放一个非碰撞道具（旧唱片、纸箱、灯泡），打破平铺重复
- 遮罩：柔边圆形视野；边缘加轻微纸张纤维/暗角
- 地面投影：猫和道具有软阴影，增强纸雕层叠感

## 7. 道具与碎片

- 碎片：**黑胶碎片**，边缘有彩虹反光 + 青蓝光，不要水晶
- 蝴蝶：纸折蝴蝶，翅膀有音符纹
- 萤火虫：暖黄小光点 + 纸翼
- 鲜花酒：小玻璃瓶，玫瑰色液体
- 猫条：撕开的包装，奶油/琥珀
- 下水道：铁栅格，冷灰蓝
- 小鱼干：纸袋/鱼形，暖黄
- 毛线球：玫瑰红线团，带线头
- 黑羽：深紫黑羽毛，边缘微光
- 出口：旧唱片封套形状的门 + 声波光柱

## 8. 动效与 VFX

- 菜单：卡片像纸张轻微浮动；选中时封套抽出
- 拾取：碎片化成音符粒子，飞向 HUD 音轨
- 1 秒静音：粒子停住、暗角收拢、画面轻微去色
- 高潮：青蓝音波从 CD 扩散，暖光恢复
- CD 拼合：碎片沿弧线飞入，最后“咔哒”合拢
- 超时：暖色门光 + 主人剪影，画面缓慢压暗
- 全局：少量纸纤维/灰尘，不要高频噪点

## 9. 字体建议

- 标题：手写感/旧印刷感中文字体（如霞鹜文楷，使用前确认授权）
- 正文：清晰黑体（HarmonyOS Sans / 思源黑体）
- 数字：略圆润，适合倒计时
- 不要全篇用同一款手写体；正文必须可读
- 中英文都要覆盖；英文可比中文更简洁

## 10. 音乐与美术的对应

推荐音乐气质：

```text
音乐盒 + 拨弦 + 轻刷鼓 + 暖 pad
80 BPM，D 小调
```

不要：

- EDM 强 drop
- 8-bit 芯片音
- 恐怖片低频轰鸣

音乐越“旧唱片/室内乐”，和纸雕回廊越统一。

## 11. 不推荐的方向

| 方向 | 问题 |
|---|---|
| 纯黑极简 + 系统字 | 当前占位感，缺少作品气质 |
| 霓虹赛博 | 和猫/旧唱片/温暖结局冲突 |
| 写实恐怖 | 超时是“被主人抱回家”，不是恐怖游戏 |
| 高细节厚涂水彩 | 成本高，小屏幕容易糊，遮罩下看不清 |
| 像素风 | 可以做，但需要全套统一，且音乐/雾气表现受限 |

## 12. 备选方向

### 备选 A：复古唱片 / Art Deco

- 深绿 + 黄铜 + 奶油，几何线条，唱机控制台
- 优点：UI 很高级，适合音乐主题
- 风险：容易偏冷，猫的温度不够，角色需要更强造型

### 备选 B：手绘水彩童话

- 暖黄、纸张、柔和边缘
- 优点：温暖、治愈
- 风险：成本最高，细节在 2 格视野下容易糊

### 备选 C：纸艺定格动画

- 真实纸张纹理、层叠阴影、轻微定格感
- 优点：辨识度最高
- 风险：动画工作量大，需要统一光源

> 推荐主方向仍是“纸雕绘本 + 旧唱片 UI”，可以吸收 Art Deco 的 UI 线条，但不要变成冷调装饰风。

## 13. 第一批先做什么

不要一次性画 100 张。先做 4 张关键稿，确认风格：

1. **菜单主视觉**：1080×1920，标题 + 3 张难度卡 + 猫剪影
2. **局内一帧**：2 格视野、猫、碎片、地板/墙、HUD
3. **老八三视图/四方向**：行走 + 待机
4. **结算一帧**：完整 CD + 票根式结算面板

这 4 张确认后，再批量做：

```text
UI 图集 → 图标 → 猫动画 → 道具/地板/墙 → 插画 → 音频
```

## 14. 验收一句话

最终画面应该让人一眼说出：

> “这是一只猫在旧唱片回廊里，把音乐一点点找回来的故事。”

如果画面看起来像“通用暗色 Roguelike + 系统 UI”，就还没有达到目标。
